2. [ ] ตรวจ checksum แตก ZIP ทั้งโฟลเดอร์ เปิด Start.cmd ได้ ไม่มีหน้าต่าง error
3. [ ] ปุ่มข้อมูลจำลองใหม่แสดง ON และ OFF ตาม DEMO mapping ภาษาไทยอ่านได้ ปรับขนาดหน้าต่าง/เลื่อนตารางได้
4. [ ] ตัดอินเทอร์เน็ตแล้วพรีวิว/export ได้ เปิด CSV ภาษาไทยถูกต้อง มี hash, reason, DRY_RUN และไฟล์ต้นฉบับคงเดิม
5. [ ] เปิด synthetic Tag Configuration แล้วไม่มีสถานะ ปุ่ม export สถานะปิด
6. [ ] ลอง UTF-8/UTF-16 และ Tab/semicolon/comma ด้วย sample; sample เวลาคงที่อาจ STALE ตามที่ควรเป็น
7. [ ] หลังบันทึก dry-run ปิดและเปิดใหม่ด้วย data-dir เดิม พบรายการซ้ำ ไม่มีการส่งเครือข่าย
8. [ ] เวลาเก่า/อนาคต, quality ไม่ผ่าน, Tag ไม่อนุญาต, ค่าไม่ใช่ 0/1 เป็น UNKNOWN/ERROR
9. [ ] การส่ง Telegram โดยไม่มีโปรไฟล์อนุมัติถูกปฏิเสธ โปรแกรมค่าเริ่มต้นเป็น dry-run
10. [ ] หากอนุมัติ Telegram แล้วเท่านั้น ตั้ง token ใน environment, ยืนยัน machine/recipient hash และเลขอนุมัติ ส่งเฉพาะข้อความ TEST จำลอง ตรวจผู้รับถูกต้อง และการกดซ้ำถูกกัน
