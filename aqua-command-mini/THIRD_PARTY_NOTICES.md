# Runtime and build tools

Application source uses Python standard library only. The portable bundle includes the CPython runtime, Tcl/Tk, and the PyInstaller bootloader.

- CPython: PSF License and bundled notices, distributed as `PYTHON_LICENSE.txt` in the Windows bundle. Source: https://www.python.org/ and https://docs.python.org/3/license.html
- Tcl/Tk: permissive terms included in `_internal/_tk_data/license.terms` in the GUI bundle. Source: https://www.tcl-lang.org/software/tcltk/license.html
- PyInstaller: GPL with an exception for distributing built applications; https://pyinstaller.org/en/stable/license.html

No Telegram credential is included. No original station export is included. Build tools are not installed on the station.
